# Cyber Security Internship — Task 2
## Analyze a Phishing Email Sample

This repository contains the materials for Task 2.

### Folder contents
- `01_Sample_Email/sample_email.txt` — fictional training email.
- `02_Header_Analysis/sample_header.txt` — fictional header for learning about header fields.
- `03_Report/Analysis_Report.md` — editable report content.
- `03_Report/Analysis_Report.docx` — editable Word report.
- `03_Report/Analysis_Report.pdf` — PDF copy of the report.
- `04_Screenshots/` — add your own genuine screenshots here.

### How to complete the task
1. Read the simulated email in `01_Sample_Email`.
2. Identify the warning signs listed in the report and understand why they are suspicious.
3. Review the simulated header in `02_Header_Analysis`.
4. Open the Word report and fill in your name, college, and date.
5. Add genuine screenshots to `04_Screenshots` if required by your coordinator.
6. Review the report and upload this folder to a new GitHub repository for Task 2.

### Important safety and accuracy notes
- The email and header are fictional training examples.
- The example link is a non-functional placeholder. Do not visit it.
- No actual online header-analyzer result is included.
- Do not click links or open attachments in real suspicious emails.
- Do not upload private email headers or personal information to public analysis websites.
- Do not add fake screenshots or claim that you performed an analysis that you did not perform.
